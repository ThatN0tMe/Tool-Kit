# Tool-Kit
<b>Description:</b> Use Tool-Kit in the terminal and input valid commands to run and control different programs<br><br><br>

# Valid Commands:
  <b>#Tool-Kit</b> --install -program_name<br>
  <b>#Tool-Kit</b> --uninstall -program_name<br>
  <b>#Tool-Kit</b> --run -program_name<br>
  <b>#Tool-Kit</b> --list -programs<br>
  <b>#Tool-Kit</b> --list -commands<br>

  <b>#Tool-Kit</b> ---> Access the core options<br><br><br>

# Tool-Kit Programs:
  <b>#Program_Name</b> - Description<br>
  <b>#N/A</b> - N/A<br>
  <b>#N/A</b> - N/A<br>
